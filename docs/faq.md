## 启动相关

### 启动时报「Port already in use」

某个端口（35565 / 35577 / 35599 / 35598）已被占用。请检查是否有残留进程：

```bash
# Linux
lsof -i :35565

# Windows
netstat -ano | findstr 35565
```

关闭占用进程，或修改代码中的端口后重新构建。

### 忘记 Root 管理员密码

Root 密码无法通过界面找回。可连接数据库后重置：

1. 找到 `root_info` 表（SQLite 为 `data.db`）。
2. 用程序使用的 Argon2 哈希算法生成新密码哈希，或删除 `root_info` 中的记录后重新执行安装流程（**注意**：删除记录会触发 Root 完整性保护，管理端将被锁定，需谨慎）。

> 建议在生产环境中妥善保管 Root 凭据，并保留数据库备份。

### 管理端显示「数据库核心遭到篡改！」

说明 `root_info` 表中的记录数不为 1（被删除或重复插入）。这是 Root 完整性保护机制。请检查 `root_info` 表，恢复为恰好一条记录后重启程序。

### 如何重新安装

1. 停止程序。
2. 备份并移走运行目录中的 `sql.yml`、`.INSTALLED` 及数据库文件（若使用 SQLite）。
3. 重新启动，程序会再次进入安装向导。

## 部署相关

### 反向代理后，日志中的 IP 都是代理地址

请确保反向代理设置了 `X-Forwarded-For` / `X-Real-IP` 请求头，且由代理覆盖客户端自带值。详见[部署与运维](deployment.md#关于客户端-ip)。

### 通过域名访问时接口跨域失败

程序内置的跨域白名单为 `localhost`。推荐将用户端与 API 放在**同一域名**下（按路径区分），见[部署与运维](deployment.md#反向代理)。

### 自定义图标不生效

- 确认在运行目录（与 JAR 同级）创建了 `icons/` 文件夹。
- 确认图标文件命名为 `app.ico`（或对应文件名）。
- 需要**重启程序**（程序在启动时检测 `icons/` 目录）。
- 管理端「应用信息」中的图标始终为内置图标，这是预期行为。

详见[自定义](customization.md#图标)。

### 修改语言包不生效

- 确认修改的是运行目录下 `i18n/` 中的文件（程序启动时会释放内置语言包到该目录）。
- 外部语言包与内置包深度合并，外部优先；若键名拼写错误则回退内置。
- 尝试重启程序或强制刷新页面。

## 认证相关

### Minecraft 客户端无法登录

1. 确认认证服务器地址填写的是 **API 根地址**（35577，或经反向代理的同源地址）。
2. 用户名填写**角色名**（不是账号用户名），密码填写该角色的 **Yggdrasil Token**。
3. 确认该用户未被封禁、邮箱已验证（若开启邮箱验证）。
4. 确认该用户所在用户权限组包含 `user.accessible`。
5. 查看程序日志中的认证错误信息。

### 提示「Invalid credentials」

- 角色名或 Token 错误。
- 用户被移入封禁组。
- 邮箱未验证（开启了邮箱验证）。
- Token 已因重新生成而失效。

### 皮肤/披风在游戏中不显示

- 确认「API 域名 / 通用域名」设置正确，且 `/textures/{type}/{hash}` 可被公网访问。
- 确认纹理的可见性设置允许被访问。
- 确认签名模式与客户端兼容。

## 配置相关

### 邮箱验证码收不到

1. 在管理后台「系统管理 → 邮箱服务器配置」中确认 SMTP 配置正确。
2. 使用「发送测试邮件」验证配置（记得先保存配置）。
3. 检查垃圾邮件文件夹。
4. 查看程序日志中的邮件发送错误。

### 修改 SMTP 后测试邮件仍用旧配置

测试邮件使用**已保存**的配置。请先点击对应区域的「保存」按钮，再发送测试邮件。

### 数据库连接失败

- 检查 `sql.yml` 中的连接信息。
- 确认数据库服务已启动、网络可达、账号有权限。
- MySQL / PostgreSQL 需提前创建数据库。
- SQLite 需确保运行目录可写。

## 升级相关

### 升级后数据会丢失吗

不会。升级只需替换 JAR，程序会在启动时自动执行数据库结构迁移。升级前建议备份，详见[部署与运维](deployment.md#升级)。

### 升级后需要重新登录吗

通常不需要。但若切换了签名模式或重新生成了密钥，客户端需要重新登录。

## 其他

### 程序会自动创建哪些文件

- `sql.yml`、`.INSTALLED`（安装时）
- SQLite 数据库文件（若使用 SQLite）
- `skins/`、`capes/`（上传纹理时）
- `logs/`（运行时）
- `i18n/`（启动时释放内置语言包）

程序**不会**创建 `icons/` 目录，需要你手动创建。

### 如何关闭遥测

遥测默认关闭。如需确认，可在管理后台「系统管理」中检查「遥测上报」开关。
