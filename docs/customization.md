# 自定义

本页介绍如何自定义图标、首页内容、语言与邮件模板。

## 图标

程序内置了一套图标（打包在 JAR 内），同时支持用户通过运行目录下的 `icons/` 文件夹进行覆盖。

### 覆盖规则

- 程序**启动时**检查运行目录下是否存在 `icons/` 文件夹。
- **存在**：`/icons/*` 会优先返回 `icons/` 中的同名文件；若某个文件缺失，则回退到内置图标。
- **不存在**：全部使用内置图标。
- 程序**不会**自动创建或释放 `icons/` 文件夹，你需要**手动创建**它。

### 使用步骤

1. 在运行目录（与 JAR 同级）创建 `icons/` 文件夹。
2. 将你的图标文件放入其中，命名为 `app.ico`（以及其他需要的文件名）。
3. 重启程序。

```text
运行目录/
├── LingYggdrasil-2.0.1.jar
└── icons/
    └── app.ico        # 你的自定义图标
```

### 内置图标始终可用

无论是否存在外部覆盖，内置图标始终可通过 `/builtin-icons/*` 访问。例如：

- `/icons/app.ico`：外部优先，缺失回退内置。
- `/builtin-icons/app.ico`：始终为内置图标。

管理后台「应用信息」页面中，程序名称旁的图标**始终使用内置图标**，不受外部覆盖影响，以保证品牌标识一致。

### 支持的文件类型

按扩展名自动设置 Content-Type，支持 `ico`、`png`、`svg`、`jpg`/`jpeg`、`gif`、`webp`。文件名仅允许字母、数字、`.`、`_`、`-`，且不得包含 `..`。

## 首页内容

首页正文不再由后台配置，而是由各语言的 HTML 模板渲染：

- 内置模板位于 `src/main/resources/i18n/index-page/{语言代码}.html`。
- 程序启动时会释放到运行目录的 `i18n/index-page/` 文件夹（若不存在）。
- 外部文件优先于内置模板；当前语言缺少模板时回退到默认语言（`zh-CN`）。

模板即首页主内容区（`<div class="main-container">` 内部）的完整 HTML，可直接编辑其中的文案与结构。支持两类占位符：

- `{{siteName}}`：站点名称（来自「系统管理 → 基本设置」）。
- `{{account}}`：登录状态相关的按钮区块（未登录为「登录 / 注册」，已登录为仪表盘与登出）。

此外，任意 `{{i18n.key}}` 标记都会按当前语言包替换，例如 `{{common.save}}`。

> 模板以原始 HTML 注入，请仅使用可信内容，避免引入脚本。

## 多语言

泠 Yggdrasil 内置简体中文（`zh-CN`）、繁体中文（`zh-TW`）、中文（華夏，`zh-XIA`）、英文（`en-US`）、俄文（`ru-RU`）、德文（`de-DE`）、法文（`fr-FR`）、意大利文（`it-IT`）、日文（`ja-JP`）、韩文（`ko-KR`）等语言，语言包为 JSON 格式。

### 外部语言包

程序启动时会：

1. 将内置语言包与首页模板释放到运行目录的 `i18n/` 文件夹（若不存在）。
2. 读取 `i18n/` 下的语言包，并与内置包**深度合并**：外部文件中存在的键覆盖内置，缺失的键回退内置。

因此，你可以在不改动程序的情况下修改文案：

```text
运行目录/
└── i18n/
    ├── zh-CN.json
    ├── en-US.json
    └── index-page/
        ├── zh-CN.html
        └── en-US.html
```

编辑对应 JSON 中某个键的值，重启程序（或重新打开页面）即可生效。

### 新增语言

新增语言需要修改源码：

1. 在 `I18n.SUPPORTED_LOCALES` 中添加一条 `LocaleOption`（语言代码与显示名）。
2. 在 `src/main/resources/i18n/` 下添加对应语言的 JSON 语言包。
3. 在 `src/main/resources/i18n/index-page/` 下添加对应语言的首页 HTML 模板。

语言下拉菜单会由 `I18n.supportedLocales()` 自动生成。

## 邮件模板

在管理后台「系统管理 → 邮箱服务器配置」中可编辑三类邮件模板：

- **注册验证邮件内容**（`mail_template_verify`）
- **邮箱变更邮件内容**（`mail_template_email_change`）
- **密码变更邮件内容**（`mail_template_password_change`）

模板支持 HTML，使用 `{code}` 占位符表示验证码，例如：

```html
<h2>你的验证码</h2>
<p>验证码：<strong>{code}</strong></p>
<p>如非本人操作，请忽略本邮件。</p>
```

此外，「测试邮件内容」用于「发送测试邮件」功能，默认正文为 `Test Email`。

## 名称黑名单通配符

用户名、角色名、皮肤/披风名的黑名单均支持通配符 `*`：

```text
admin*
*test*
badword
```

- 用户名、角色名：命中即拒绝。
- 皮肤/披风**别名**：命中即拒绝。
- 皮肤/披风**原名**：命中时静默替换为 `x`（保留扩展名），不中断上传。

可启用「大小写严格」模式以区分大小写。
