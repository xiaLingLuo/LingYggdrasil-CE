# 管理后台指南

管理后台运行在 **35599** 端口，使用安装时创建的 Root 管理员账户登录。登录地址：

```text
http://<服务器地址>:35599/admin/login
```

> 管理后台应保持私密，请勿直接暴露到公网，详见[部署与运维](deployment.md)。

## 权限与可见性

管理后台的功能受**权限系统**控制。Root 账户拥有全部权限；其他管理员按其所在权限组显示可用菜单与操作。无权限的页面与接口会被拒绝。详见[权限系统](permissions.md)。

侧边栏中的「管理员」与「世界树」仅对 Root 显示。

## 仪表盘

展示用户数、角色数、皮肤/披风数量等核心数据，并提供快捷入口。仪表盘组件支持拖拽排序。

## 用户管理

### 用户名册

- 查看全部用户，支持按关键字搜索。
- 编辑用户邮箱、重置/查看状态。
- 切换**邮箱验证状态**（可点击徽章）。
- 将用户分配到用户权限组。
- 创建用户（用户名、邮箱、密码、昵称、邮箱验证状态）。
- 删除用户。

### 用户名黑名单

配置禁止注册的用户名列表，支持通配符 `*` 与「大小写严格」模式。命中即拒绝注册。

## 角色管理

### 角色名册

- 查看全部角色，支持按名称或 UUID 搜索。
- 修改角色名称、转移所有权（通过名称/用户旁的铅笔图标）。
- 切换角色形态（传统/纤细，点击徽章切换）。
- 清除角色当前皮肤/披风（重置材质）。
- 创建角色（按钮位于标题行右侧）。

### 角色名黑名单

配置禁止使用的角色名，逻辑同用户名黑名单。

## 皮肤 / 披风管理

### 名册

- 查看全部纹理资源，支持下载与 3D 预览。
- 修改别名、删除纹理。
- 「删除所有无主皮肤/披风」：清理无原始上传者的材质，并一并清理磁盘上无数据库记录的孤立文件。

### 设置

配置单文件大小上限、数量上限、总大小上限、频率限制、存储路径与是否允许下载。

### 名称黑名单

皮肤/披风别名命中即拒绝；原名命中时静默替换为 `x`（保留扩展名）。

## 安全设置

以可视化卡片展示 1–6 级加密等级，调整后影响用户密码的哈希强度。等级越高越安全，但计算开销也越大。

> 修改加密等级只影响**之后**创建/修改的密码哈希，已有密码保持原强度直到下次修改。

## 系统管理

系统管理页面包含多张设置卡片，每张卡片有独立的保存按钮（邮箱配置进一步拆分为 5 个独立保存区域）。各设置项含义详见[配置参考](configuration.md#二系统设置)。

- 站点信息
- 功能开关
- 域名
- 邮箱域名控制
- 邮箱服务器配置（含「发送测试邮件」）
- 名称黑名单（用户名/角色/皮肤/披风）
- 皮肤/披风设置
- 用户限制
- 公告
- 备案信息
- 用户操作日志
- 其他（默认语言、遥测等）

### 发送测试邮件

在「邮箱服务器配置 → 测试邮件」区域：

1. 填写「目标邮箱」。
2. （可选）修改「测试邮件内容」。
3. 点击「发送测试邮件」。

发送使用**已保存**的邮件配置，因此若刚修改了 SMTP 设置，请先点击对应区域的「保存」再测试。

### 清除缓存

「系统管理」提供清除缓存的入口。

## 管理员管理（仅 Root）

- 查看管理员列表。
- 创建管理员（用户名、密码、邮箱、权限组）。
- 编辑管理员信息与权限组。
- 删除管理员。

> 权限组中的高危权限（如 `admin.admins.*`、`admin.groups.edit`、`admin.usergroups.edit`）在界面上以红色警告图标标注，点击可查看风险说明。这些权限允许持有者提升自己或他人为近乎 Root 的账户，请谨慎授予。

## 权限组（仅 Root）

- 管理**管理员权限组**：创建、编辑权限、删除。
- 管理**用户权限组**：创建、编辑权限、删除；内置用户组（如 `default`、`banned`）不可修改或删除。

权限组名称创建后不可修改，如需改名请删除后重建。详见[权限系统](permissions.md)。

## 世界树设置（仅 Root）

- 配置签名模式（Ed448 / RSA-SHA512 / RSA-SHA1）。
- 生成 / 重新生成签名密钥。
- 配置 Token 有效期、单角色 Token 上限、认证频率限制、批量查询上限、UUID 版本等。

> 重新生成密钥或切换签名模式后，客户端需要重新登录。

## 应用信息

展示程序名称、版本、仓库地址、安装时间。程序名称旁始终显示**内置图标**（不受用户自定义图标覆盖影响）。

> 更多运维与安全建议见[部署与运维](deployment.md)与[安全说明](security.md)。
