# 管理端界面自定义

本页介绍如何自定义管理后台（35599）的图标、语言与邮件模板。用户端界面自定义见[用户端界面自定义](../02-user/customization.md)。

## 图标

程序内置了一套图标（打包在 JAR 内），同时支持用户通过运行目录下的 `icons/` 文件夹进行覆盖。

### 覆盖规则

- 程序**启动时**检查运行目录下是否存在 `icons/` 文件夹。
- **存在**：`/icons/*` 会优先返回 `icons/` 中的同名文件；若某个文件缺失，则回退到内置图标。
- **不存在**：全部使用内置图标。
- 程序**不会**自动创建或释放 `icons/` 文件夹，你需要**手动创建**它。

### 使用步骤

1. 在运行目录（与 JAR 同级）创建 `icons/` 文件夹。
2. 将你的图标文件放入其中，命名为 `app.ico`（以及其他需要的文件名）。
3. 重启程序。

```text
运行目录/
├── LingYggdrasil-2.2.2.jar
└── icons/
    └── app.ico        # 你的自定义图标
```

### 内置图标始终可用

无论是否存在外部覆盖，内置图标始终可通过 `/builtin-icons/*` 访问。例如：

- `/icons/app.ico`：外部优先，缺失回退内置。
- `/builtin-icons/app.ico`：始终为内置图标。

管理后台「应用信息」页面中，程序名称旁的图标**始终使用内置图标**，不受外部覆盖影响，以保证品牌标识一致。

### 支持的文件类型

按扩展名自动设置 Content-Type，支持 `ico`、`png`、`svg`、`jpg`/`jpeg`、`gif`、`webp`。文件名仅允许字母、数字、`.`、`_`、`-`，且不得包含 `..`。

## 多语言

管理端语言包为 JSON 格式，位于 `src/main/resources/i18n/admin/`，程序启动时释放到运行目录的 `i18n/admin/` 文件夹。

- 外部文件与内置包**深度合并**：外部存在的键覆盖内置，缺失的键回退内置。
- 用户端多语言的完整机制（外部语言包、新增语言）见[用户端界面自定义 → 多语言](../02-user/customization.md#多语言)。

```text
运行目录/
└── i18n/
    └── admin/
        ├── zh-CN.json
        └── en-US.json
```

## 邮件模板

在管理后台「系统管理 → 邮箱服务器配置」中可编辑三类邮件模板：

- **注册验证邮件内容**（`mail_template_verify`）
- **邮箱变更邮件内容**（`mail_template_email_change`）
- **密码变更邮件内容**（`mail_template_password_change`）

模板支持 HTML，使用 `{code}` 占位符表示验证码，例如：

```html
<h2>你的验证码</h2>
<p>验证码：<strong>{code}</strong></p>
<p>如非本人操作，请忽略本邮件。</p>
```

此外，「测试邮件内容」用于「发送测试邮件」功能，默认正文为 `Test Email`。
