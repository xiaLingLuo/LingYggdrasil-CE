# 插件管理

本页面向服务器管理员，介绍如何安装、查看与启停插件。插件开发见[插件开发手册](../07-plugin-dev/guide.md)。

> ⚠️ **安全提示**：插件是**完全可信代码**，拥有与主程序相同的权限（可访问数据库、配置与服务器对象）。请勿加载来路不明的插件，加载第三方插件后果自负。

## 安装插件

1. 在运行目录（与 JAR 同级）创建 `plugins/` 文件夹（正常模式首次启动也会自动创建）。
2. 将插件 jar 放入其中。
3. 重启程序，或对已加载的插件使用后台「重载」。

程序启动时扫描 `plugins/` 下的所有 `*.jar`，读取其中的 `plugin.yml`；缺少必填字段或使用保留名称的 jar 会被忽略。

```text
运行目录/
├── LingYggdrasil-2.2.7.jar
└── plugins/
    ├── plugins-state.json   # 启停状态（自动生成，只增不减）
    ├── HelloWorld.jar
    └── HelloWorld/          # 插件私有数据目录
        └── logs/            # 插件自身日志
```

## 后台「插件管理」

管理后台的一级菜单「插件管理」下含：

- **总览**：以卡片形式展示每个插件的图标、名称、版本、作者、介绍与运行状态，并提供启停/重载按钮。
- **插件自定义二级菜单**：插件可注册**至多一个**二级菜单，承载其自身控制功能。

## 运行状态

| 状态 | 含义 |
|------|------|
| 运行中 | 已加载并启用 |
| 已停止 | 被管理员停止；只展示元信息，不加载代码 |
| 依赖缺失 | 声明的硬依赖不存在；点击状态旁 `?` 可查看依赖列表 |
| 加载失败 | 主类缺失、实例化异常等 |
| 版本不兼容 | 插件声明的 API 版本与服务端不匹配 |

## 启停与重载

- **启停状态持久化**：保存在 `plugins/plugins-state.json`，**只增不减**，不会自动清理。删除的 jar 对应记录会保留但被忽略，可手动清理。
- **首次发现默认启用**。
- **热重载**：`hotReloadable: true` 的插件可在后台停止/启动/重载；`hotReloadable: false` 的插件无法在后台启停，点击按钮会提示「作者声明本插件无法热重载」，其首次发现后默认启用，需随进程停止而关闭。
- 硬依赖缺失 / 版本不兼容 / 加载失败的插件，其「期望启用」状态会被保留，补齐依赖或升级后重启即可自动加载。

## 日志

- **插件系统日志**：`logs/plugin/plugin-<日期>.log`，仅包含 LingYggdrasil 插件系统自身的日志。
- **插件自身日志**：`plugins/<name>/logs/<name>-<日期>.log`，由插件通过标准日志 API 写入。

两类日志均按天切分，保留天数由 `config.yml` 的 `logging.pluginSystem.retentionDays` 控制（插件自身日志同样遵循该值）；`logging.pluginSystem.enabled: false` 可关闭插件系统日志。详见[配置参考](../01-overview/configuration.md#一configyml)。

## 插件路由

插件可以在**用户端**与**世界树 API** 上注册**未被占用**的路由点，并完全接管其响应；不能覆盖 LingYggdrasil 内置路由。多个插件注册同一路由时，先注册者生效，冲突会记入插件系统日志。详见[插件开发手册](../07-plugin-dev/guide.md#6-后台菜单与-api)。
