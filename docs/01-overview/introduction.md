# 项目简介

**泠 Yggdrasil** 是一个为 Minecraft 打造的 **Yggdrasil 外置鉴权系统**，完整兼容 authlib 体系，提供账户注册、登录、角色管理、皮肤/披风托管与好友分享能力。内置 Web 安装向导、二次元风格管控面板与多层级安全体系。

> **在线预览**：[ygg.minecraft.ist](https://ygg.minecraft.ist/)

## 服务端口

| 端口 | 用途 | 访问范围 |
|---|---|---|
| `35565` | 用户端（注册/登录/仪表盘/纹理/好友/个人主页） | 对外公开 |
| `35577` | Yggdrasil API（供 Minecraft 启动器调用） | 对外公开 |
| `35599` | 管理后台 | **应保持私密** |
| `35598` | 安装向导 | 仅首次安装时开放 |

> **安全提醒**：管理后台（35599）与安装端口（35598）不应直接暴露到公网，建议通过反向代理限制来源，或仅经内网 / SSH 隧道访问。

## 功能特性

### 开箱即用

- **Web 安装向导**：首次启动引导设置管理员账户、外网 URL、数据库与邮件服务。
- **多数据库**：SQLite、MySQL / MariaDB 按需选择（PostgreSQL 驱动随包，方言暂未启用）。
- **单 JAR 部署**：一个可执行 JAR 放入服务器即可运行。
- **三种 Yggdrasil API 模式**：默认 / 独立 / 聚合。

### 用户系统

- **角色管理**：创建多个游戏角色，每个角色拥有独立的 UUID 与世界树密钥。
- **纹理管理**：上传、管理个人皮肤与披风，支持别名、公开/私有可控。
- **公共画廊 / 点赞**：按热度浏览公开纹理并点赞。
- **好友系统**：好友码添加、申请处理、拉黑、分享纹理。
- **个人主页**：公开展示用户作品；注销用户统一遮罩。
- **3D 皮肤预览 / 安全设置 / 操作日志 / 主题与语言**。

### 管理系统

- **仪表盘、用户管理、角色管理、纹理资产名册、系统设置、权限组、Root、邮件、公告、日志、插件管理**。

### Yggdrasil 协议

- 认证/刷新/验证/登出、加入/查询、角色查询与材质下载。
- 三种签名模式：Ed448 / RSA-SHA512 / RSA-SHA1。
- 默认 / 独立 / 聚合三种 API 模式。

### 插件系统

- 稳定 SPI（`plugins/spi/`）、旧 API 桥接（`plugins/legacy/`）与传统 `plugin.yml` 插件；支持动态权限节点、菜单与路由扩展。

### 安全体系

- Argon2id 密码加密、邮箱验证、同 IP 注册限制、名称黑名单。
- 三端独立会话、CSRF、CSP nonce、限流、上传校验。
- 世界树密钥加密存储、审计事件、配置文件密码加密、Root 完整性保护。
