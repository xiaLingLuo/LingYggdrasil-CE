# 项目简介

**泠 Yggdrasil** 是一个为 Minecraft 打造的 **Yggdrasil 外置鉴权系统**，完整兼容 authlib 体系，提供账户注册、登录、角色管理与皮肤/披风托管能力。内置 Web 安装向导、二次元风格的管控面板与多层级安全体系，让你在几分钟内搭起一套安全又好看的外置登录服务。

> **在线预览**：[multimc.cn](https://multimc.cn/) —— 一个运行着最新稳定版的站点。

## 服务端口

| 端口    | 用途                                       | 访问范围         |
|---------|--------------------------------------------|------------------|
| `35565` | 用户端（注册、登录、仪表盘、皮肤、好友等） | 对外公开         |
| `35577` | Yggdrasil API（供 Minecraft 启动器调用）   | 对外公开         |
| `35599` | 管理后台                                   | **应保持私密**   |
| `35598` | 安装向导                                   | 仅首次安装时开放 |

> **安全提醒**：管理后台（35599）与安装端口（35598）不应直接暴露到公网，建议通过反向代理限制来源，或仅经内网 / SSH 隧道访问。

## 功能特性

### 开箱即用

- **Web 安装向导** —— 首次启动自动引导设置管理员账户、数据库与邮件服务。
- **多数据库支持** —— SQLite、MySQL 按需选择（PostgreSQL 代码保留，暂不可用）。
- **单 JAR 部署** —— 打包为单个可执行 JAR，放入服务器即可运行。

### 用户系统

- **角色管理** —— 创建多个游戏角色，每个角色拥有独立的 Yggdrasil Token 与 UUID。
- **皮肤 & 披风** —— 上传、管理个人皮肤与披风，支持别名、公开/私有可控。
- **材质库** —— 公共材质广场，按热度排序，无限滚动懒加载。
- **点赞 & 收藏 / 共享材质** —— 点赞助力上热门，收藏到个人共享材质库。
- **好友系统** —— 好友代码添加、详情卡片、拉黑管理、勾选式材质共享。
- **3D 皮肤预览 / 安全设置 / 操作日志 / 主题与语言**。

### 管理系统

- **仪表盘总览**、**用户管理**、**角色管理**、**皮肤 & 披风管理**、**安全设置**、**系统管理**、**权限组**、**世界树设置**。

### 插件系统

- 外部插件加载、动态权限节点、插件开发 API 与后台插件管理。

### Yggdrasil 协议

- 完整协议实现，三种签名模式（Ed448 / RSA-SHA512 / RSA-SHA1），纹理托管与扩展查询。

### 安全体系

- Argon2 密码加密（6 级强度）、邮箱验证、同 IP 注册限制、名称黑名单、独立会话体系、Root 完整性保护、限流。

## 技术栈

| 组件       | 技术                                                                 |
|------------|----------------------------------------------------------------------|
| 语言       | Java 25                                                              |
| Web 框架   | [Javalin](https://javalin.io/)                                       |
| 数据库连接 | [HikariCP](https://github.com/brettwooldridge/HikariCP) 连接池       |
| 数据库     | SQLite / MySQL（PostgreSQL 代码保留，暂不可用）                      |
| 加密       | [Bouncy Castle](https://www.bouncycastle.org/)（Argon2、Ed448、RSA） |
| 邮件       | [Eclipse Angus Mail](https://eclipse-ee4j.github.io/angus-mail/)     |
| 日志       | Logback + SLF4J                                                      |
| 序列化     | Jackson                                                              |
| 构建工具   | Maven                                                                |
