# 用户功能指南

用户端运行在 **35565** 端口：

```text
http://<服务器地址>:35565
```

> 管理后台见[管理后台指南](../03-admin/guide.md)；启动器接入见 [Yggdrasil API](../04-yggdrasil/api.md)。

## 注册与登录

1. 用户端首页 → 「注册」，填写用户名、邮箱、密码（规则由站点设置决定）。
2. 若站点开启邮箱验证，注册后需输入邮箱验证码完成验证。
3. 登录后进入仪表盘；仪表盘展示当前 API 模式对应的认证服务器地址与快速指引。
4. 支持账号名或邮箱登录；管理员可关闭「账号密码外置登录」，此时仅能使用角色世界树密钥登录游戏。

## 仪表盘与设置

- **仪表盘**：账号概览、快捷入口、快速使用指南。
- **设置**（`/settings`）：
  - 修改昵称/邮箱/密码（需当前密码，邮箱验证开启时需验证码）；
  - 外部登录开关（若允许自助修改）；
  - 拉黑名单管理；
  - 操作日志查看/下载/清空；
  - 主题（浅色/深色）与语言；
  - **账户注销**：二次 challenge 校验后切到 `cancelled` 权限组，业务数据保留并统一遮罩。

## 角色管理

路径：`/profiles`。

- **创建角色**：每个角色拥有独立 UUID、名称与**世界树密钥**；角色名长度受管理员配置限制。
- **编辑角色**：名称、皮肤模型（默认/纤细）。
- **世界树密钥**：角色编辑弹窗中查看/复制/轮换。默认虚化显示；轮换后旧密钥立即失效，请同步更新启动器密码。
- **纹理绑定**：弹窗内新增皮肤/披风选择器：
  - 来源一：**我上传的纹理**（UPLOAD 资格）；
  - 来源二：**好友授权给我的纹理**（SHARE_GRANT，带 🔗 标记）；
  - 选择后立即调用 `PUT /api/profiles/{id}/textures/{slot}` 绑定并刷新 3D 预览；「重置」会删除绑定并清理展示。
- **删除角色**：不可恢复；相关绑定与密钥凭据会一并清理。
- **角色转移/删除后的昵称显示**：个人主页/好友处头像与昵称按当前角色/默认史蒂夫回退。

## 纹理管理

路径：`/skins`（皮肤）、`/capes`（披风）。

- 点击上传卡片选择 PNG 后先弹出上传详情卡：预览、别名、是否公开，确认后上传；
  受大小/数量/频率限制，成功后进入资产列表。
- 列表恢复旧版卡片：缩略图、名称、尺寸和公开状态；点击卡片打开详情。
- 操作：
  - **别名**：修改显示名称（`POST /api/v2/textures/{assetId}/alias`）。
  - **公开/取消公开**：发布为 public publication 或撤回（`POST /api/v2/textures/{assetId}/visibility`）。
  - **详情**：点击卡片打开详情弹窗，集中执行应用/下载/别名/可见性/删除。
  - **删除**：撤销上传并撤回发布（`DELETE /api/v2/textures/{assetId}`）；文件由存储对账延迟回收。
- 上传/库/公开记录按用户独立：相同文件（同 hash）会被复用一个 blob，但每人的上传、库、发布与互动各自独立。

## 材质库

路径：`/world`。

- 独立公开页面，无用户左侧栏；未登录也可访问。
- 卡片展示图片、名称、类型、尺寸和发布者，点击进入 `/userhome/{code}/public/{hash}` 详情页；旧 `/world/{publicationId}` 会重定向到该页。
- **点赞/收藏**：登录后可交互（`POST /api/v2/publications/{id}/like`）。

## 好友与分享

路径：`/friends`。

- **我的资料卡**：好友页首张卡片显示自己的展示角色头像、昵称和好友代码；点击可切换展示用角色。
- **好友列表**：显示好友头像、昵称和好友代码，可进入 `/userhome/{code}`。
- **添加好友**：点击卡片，输入好友代码发送申请。
- **收到的申请**：接受 / 拒绝。
- **拉黑名单**：不在好友页展示，统一在「设置 → 黑名单 → 细致管理」中查看、解除或清空。
- **分享纹理**：`/shared`展示收到的有效分享（owner 授权给你的纹理，可绑定到角色）。
- 分享授权规则：仅好友、仅来源为本人上传；原主可撤销，接收者可移除；互不影响其他来源。

## 个人主页

路径：`/userhome/{code}`。

- 公开展示该用户的公开 publication（不含上传者隐私）；
- 注销用户统一显示「账号已注销」与默认头像；
- 关注/好友申请受「无法被关注」策略约束。

## 3D 预览与主题

- 角色编辑弹窗集成 skinview3d，可 360° 旋转、切换默认/纤细模型。
- 主题与语言随账户保存；语言包支持外部覆盖。

## 操作日志

设置页可查看自己的操作日志（登录、改密、上传、绑定等），支持下载与清空（受权限与保留策略限制）。

## 客户端使用流程

1. 用户端创建角色，记录角色名与世界树密钥。
2. 上传皮肤/披风并绑定到角色（或使用好友分享）。
3. 启动器填写认证地址（见仪表盘指引），用户名=角色名，密码=世界树密钥。
4. 若更换密钥/转移角色，需要同步更新启动器。
