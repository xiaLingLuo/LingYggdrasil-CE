# 用户功能指南

用户端运行在 **35565** 端口，地址：

```text
http://<服务器地址>:35565
```

> 管理后台见[管理后台指南](../03-admin/guide.md)，客户端接入协议见 [Yggdrasil API](../04-yggdrasil/api.md)。

## 注册与登录

1. 打开用户端首页，点击「注册」。
2. 填写用户名、邮箱、密码等信息。密码规则由站点配置决定（普通用户默认至少 6 位）。
3. 若站点开启了邮箱验证，注册后需前往邮箱收取验证码并完成验证。
4. 返回登录页，使用用户名或邮箱登录。

> 邮箱域名可能受管理员配置的黑名单/白名单限制，不符合规则的邮箱无法注册。

## 仪表盘

登录后进入仪表盘，可查看账号概览、最新动态与快捷入口。仪表盘内置「快速使用指南」，指导你完成角色创建与客户端配置。

## 安全设置

在「设置」页面可自助完成：

- **修改昵称**
- **修改邮箱**：需验证当前密码，并输入邮箱验证码（若开启邮箱验证）。
- **修改密码**：需验证当前密码，并输入邮箱验证码（若开启邮箱验证）。
- **查看 / 重新生成 Yggdrasil Token**（在角色管理中操作）。

## 角色管理

路径：用户端「角色管理」（`/profiles`）。

- **创建角色**：每个角色拥有独立的 Yggdrasil Token 与 UUID。
- **查看 Token**：在角色详情中查看并复制 Token，它将作为 Minecraft 登录密码。
- **重新生成 Token**：若怀疑 Token 泄露，可立即重新生成。
- **应用材质**：在皮肤/披风详情中，将材质一键应用到指定角色。
- **重置材质**：在角色详情中将当前皮肤/披风重置为默认。
- **删除角色**。

### 将角色接入 Minecraft

1. 在启动器中添加自定义 Yggdrasil 认证服务器，地址为 API 根地址（如 `https://example.com` 或 `http://<服务器>:35577`）。
2. 用户名填写**角色名**，密码填写该角色的 **Yggdrasil Token**。
3. 登录游戏。

## 皮肤与披风

- 上传 PNG 格式的皮肤/披风。
- 为材质设置别名。
- 设置可见性：公开 / 私有。
- 下载材质、3D 预览。
- 删除材质。

上传受站点配置的大小、数量、总大小与频率限制。

## 材质库（世界树）

路径：用户端「世界树」（`/world`）。

- 浏览所有**公开**材质，按热度排序（点赞 + 收藏×5）。
- 无限滚动懒加载；未登录可预览前 100 条。
- 为材质**点赞**与**收藏**。
- 收藏有数量上限（由管理员配置）。

## 共享材质

路径：用户端「共享」（`/shared`）。

- **好友共享**：查看好友共享给你的材质，或将你的材质共享给好友。
- **我的收藏**：查看收藏的材质，可设置自定义别名，并一键应用到角色。

## 好友系统

路径：用户端「好友」（`/friends`）。

- 通过好友代码添加好友。
- 查看好友详情卡片。
- 处理好友请求（接受 / 取消）。
- 拉黑 / 解除拉黑，管理拉黑列表。
- 向好友共享材质（勾选列表）。

## 操作日志

路径：用户端「日志」（`/logs`）。

- 查看自己的操作日志（只读）。
- 查看日志用量进度。
- 下载日志（txt，受下载间隔限制）。
- 清空日志。

日志内容与保留策略由管理员配置，详见[配置参考](../01-overview/configuration.md#用户操作日志)。

## 语言与主题

- 顶部导航栏可切换**主题**（浅色 / 深色）。
- 语言菜单可在简体中文、繁体中文、中文（華夏）、English、Русский、Deutsch、Français、Italiano、日本語、한국어 间切换，选择会持久化到账户。
